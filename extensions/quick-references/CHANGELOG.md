# Quick References Changelog

## [0.2.0] - 2026-03-13

- Added global `Search Commands` for snippets, sections, and reference fallback results.
- Added in-reference section and command search with richer copy actions.
- Added first-run dataset download with local cache plus the new dataset schema and lighter runtime loading.
- Added dedicated `Update References` command and extension preferences for open mode, copy mode, and auto-update frequency.
- Added regression tests for markdown processing, copy behavior, and global command ranking.

## [0.1.0] - 2026-03-04

- Initial release of Quick References: Search and browse Fechin/reference cheat sheets with favorites, fast search, detail view, and offline support.
